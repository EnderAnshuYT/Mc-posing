# MC Posing

GitHub par app banane ke steps:

1. GitHub par naya repository banao (Public).
2. In 6 files ko repository mein upload karo: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, README.md
3. Settings > Pages mein jao. Source mein "Deploy from a branch" chuno, branch main aur folder / (root) chuno, Save dabao.
4. 1-2 minute baad link milega: https://TUMHARA-NAAM.github.io/REPO-NAAM/
5. Phone mein Chrome mein link kholo. Menu (3 dot) mein "Install app" ya "Add to Home screen" dabao.

Pehli baar internet chahiye. Uske baad app offline bhi chal jati hai.
